# おとの れんしゅう（MieeL）

ひらがなの よみかきの まえに だいじな「おとの きづき（音韻意識）」を、えと おとの ゲームで そだてる アプリです（特別支援教育向け・iPad / iPhone）。

## できること（8つの あそび × 3レベル）
- 👏 **いくつの おと？**：おとの かずだけ てを たたく（まちがえたら いっしょに 1はくずつ）
- 🔤 **はじめの おと** ／ 🔚 **おわりの おと**
- 🔎 **どこに ある？**：その おとは なんばんめ？
- 🖼️ **おなじ おとの なかま**：おなじ おとで はじまる え（もじが よめなくても できる）
- 🐍 **しりとり**：おわりの おとから つなげる
- 🎵 **ちいさい「っ」「ゃゅょ」と「ー」**：ただしい かきかたは どれ？（ケエキ・ラツパ などの まちがいと くらべる）
- 🔁 **おとを とる・ぎゃくに いう**
- ことば 140こ いじょう（え つき）、「もじを みせない」せっていも
- ⭐ と きろく（子どもごと）
- **A4 プリント**：おとの かず（○を ぬる）・ことばを かこう（はこ）・しりとり
- 🏠 ボタンで いつでも さいしょへ（ゲーム ちゅうは ながおし）

きろくは この たんまつの なかだけに ほぞん し、インターネットには おくりません。
